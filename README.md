# Калейдоскоп

Интерактивный калейдоскоп в одном HTML-файле. Ведите мышью по холсту — штрих
размножается по осям симметрии и складывается в постоянно вращающийся узор.
Ни сборки, ни зависимостей: только `<canvas>` и ванильный JavaScript.

## Запуск

Откройте `kaleidoscope/index.html` в браузере. Всё.

## Управление

| Действие | Как |
| --- | --- |
| Рисовать | вести мышью или пальцем по холсту |
| Спрятать / показать панель | клавиша `H` или кнопка ☰ |
| Очистить холст | клавиша `C` или кнопка «Очистить» |
| Авто-узор | `Пробел` — холст рисует сам |
| Сохранить картинку | кнопка «Сохранить PNG» |

## Настройки на панели

- **Оси симметрии** — сколько раз отражается штрих (2–24).
- **Толщина кисти** — ширина линии (1–40).
- **Оттенок** — цвет по HSL (0–360); перекрывается режимом «Радуга».
- **Вращение фона** — скорость вращения узора.
- **Зеркало** — добавляет зеркальное отражение в каждом секторе.
- **Радуга** — цвет плавно меняется во времени.
- **Затухание** — старые штрихи медленно растворяются.
- **Свечение** — мягкий ореол вокруг линий.

## Как это устроено

Рисунок копится в закадровом `<canvas>` (`buf`), а видимый холст каждый кадр
перерисовывает его с поворотом на `spinAngle`. Поддерживается HiDPI
(`devicePixelRatio`), а при изменении размера окна буфер переносится по центру
без потери рисунка.
