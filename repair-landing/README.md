# Лендинг: ремонт ноутбуков и телефонов на дому

Одностраничный сайт-визитка для частного мастера. Цель — чтобы посетитель
оставил заявку через форму. Чистые HTML, CSS и JS, без сборки и зависимостей.

## Запуск

Откройте `repair-landing/index.html` в браузере.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка всех блоков: шапка, главный экран, «обо мне», преимущества, форма, вопросы, футер |
| `styles.css` | Оформление. Mobile-first, переменные темы в `:root`, адаптив на `@media` |
| `script.js` | Проверка формы и отправка заявки на почту через сервис Web3Forms (`fetch`) |

## Блоки страницы

- **Главный экран** — суть услуги, две кнопки действия.
- **Обо мне** — опыт, гарантия, три коротких показателя.
- **Преимущества** — четыре карточки (выезд, бесплатная диагностика, ремонт за визит, гарантия).
- **Форма заявки** — имя, телефон, комментарий. При отправке POST-запросом уходит в Web3Forms, оттуда — письмом на почту.
- **Частые вопросы** — родная HTML-«гармошка» на `<details>`, без JS.
- **Футер** — контакты.

## Что заменить на своё

- **Ключ Web3Forms** — `WEB3FORMS_ACCESS_KEY` в начале `script.js` (см. ниже). Без него форма не отправляется.
- телефон и ссылка на WhatsApp (в `index.html`, отмечено `<!-- TODO -->`);
- имя мастера, город и текст в блоке «Обо мне».

Уже заданы: адрес «Почта» в футере `index.html` (`deadinside23200821@gmail.com`), Telegram — `@obrecchhen`.

## Как работает форма

Бэкенда нет — отправку берёт на себя бесплатный сервис **Web3Forms**.

1. Зайдите на <https://web3forms.com>, введите почту `deadinside23200821@gmail.com` —
   на неё придёт **Access Key** (строка вида `xxxxxxxx-xxxx-...`).
2. Вставьте этот ключ в `script.js` вместо заглушки `ВСТАВЬТЕ-СЮДА-КЛЮЧ-WEB3FORMS`.
3. Готово. По кнопке «Отправить заявку» `script.js` проверяет имя и телефон и
   шлёт `fetch`-запросом POST на `https://api.web3forms.com/submit`; Web3Forms
   пересылает данные письмом на вашу почту. Ключ можно светить в коде — сам
   адрес почты в нём не виден.

Бесплатный тариф — 250 заявок в месяц. В форме есть скрытое поле-ловушка
`botcheck` против спам-ботов.
