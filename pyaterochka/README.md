# Что покупать в Пятёрочке

Личная шпаргалка по полке магазина: полезные бюджетные продукты с чистым составом
и запасом белка. Отмечаешь, что положил в корзину, — внизу собирается примерный
чек. Чистые HTML, CSS и JS, без сборки и зависимостей.

## Запуск на компьютере

Откройте `index.html` двойным щелчком — сайт работает прямо с диска, сервер не нужен.

Отметки «Куплено» хранятся в `localStorage` браузера. У каждого устройства и браузера они свои: отметки с компьютера не появятся на телефоне.

## Как открыть с телефона по ссылке

Выложите папку `pyaterochka` целиком, вместе с `img/`. Оба способа бесплатные.

### Netlify Drop — быстрее всего, без Git

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `pyaterochka` в окно браузера.
3. Через несколько секунд появится ссылка вида `https://имя-сайта.netlify.app` —
   откройте её на телефоне.

Без аккаунта Netlify хранит такой сайт недолго: чтобы ссылка жила постоянно,
зарегистрируйтесь (можно через GitHub) и привяжите сайт к аккаунту. Обновить
сайт — снова перетащить папку на вкладке **Deploys**. Адрес меняется в **Site configuration → Change site name**.

### GitHub Pages — если папка лежит в репозитории

1. Отправьте папку на GitHub:

   ```bash
   git add pyaterochka
   git commit -m "Шпаргалка: что покупать в Пятёрочке"
   git push
   ```

2. В репозитории на GitHub откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку
   `main` и папку `/ (root)`, нажмите **Save**.
4. Через пару минут сайт откроется по адресу
   `https://<логин>.github.io/<репозиторий>/pyaterochka/` — для этого репозитория
   `https://timuuur.github.io/kaleidoscope/pyaterochka/`.

На бесплатном тарифе Pages работает только для публичных репозиториев. Папка
должна попасть в ту ветку, которую вы выбрали в настройках.

### Совет для магазина

Откройте ссылку на телефоне и добавьте страницу на главный экран: в Safari —
**Поделиться → На экран «Домой»**, в Chrome — **⋮ → Добавить на главный экран**.
Шпаргалка будет открываться как приложение.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка: шапка, поиск, чипсы категорий, справочные блоки, панель и окно чека |
| `style.css` | Оформление. Mobile-first, брейкпоинт 640 px, светлая и тёмная тема по `prefers-color-scheme` |
| `script.js` | Данные о товарах, карточки, поиск, фильтр, отметки в `localStorage`, подсчёт чека |
| `img/` | Фото упаковок 500 × 500, скачанные с catalog-ceny.ru |

## Как поменять список

Товары — массив `PRODUCTS` в начале `script.js`: категория, название, бренд, вес,
цена и ссылка. Новая категория сама появится в чипсах. Чтобы добавить фото,
положите картинку в `img/` и допишите строку в `PHOTOS` — ключом служит точное
название товара. Если фото нет или оно не загрузилось, на карточке будет крупная
эмодзи.

Фото 18 товаров скачаны с catalog-ceny.ru. У кефира и овсяных хлопьев ссылки нет,
поэтому у них эмодзи. Цены — ориентир на момент составления списка, на полке
могут отличаться.
